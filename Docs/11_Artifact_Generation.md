# Artifact Generation

Project: exHacker

Version: 2.0

Status: Active

---

# Purpose

Artifacts are the final outputs users consume.

Everything generated by agents eventually becomes artifacts.

Artifacts convert workflow state into actionable deliverables.

---

# Philosophy

Agents generate information.

Artifacts generate value.

A user should be able to leave exHacker and immediately begin building.

---

# Artifact Pipeline

```text
Workflow State
 ↓
Artifact Generator
 ↓
Templates
 ↓
Rendered Outputs
 ↓
Export System
```

# Artifact Generators

Each artifact should have its own generator.

Example:

```text
ReadmeGenerator

ArchitectureGenerator

ApiSpecGenerator

ImplementationGuideGenerator

PresentationGenerator

PitchGenerator
```

---

# Generator Contract

Input:

```text
Workflow State
```

Output:

```text
Structured Artifact
```

---

# Artifact Rules

---

## Rule 1

Artifacts never call LLMs directly.

Use workflow state.

---

## Rule 2

Artifacts must be deterministic.

Same state.

Same output.

---

## Rule 3

Artifacts must not invent information.

Only use state.

---

## Rule 4

Artifacts must be exportable.

---

# Export Formats

---

## Markdown

Primary format.

Reason:

* Easy generation
* Easy editing
* GitHub friendly

---

## JSON

Machine readable.

Used internally.

---

## PDF

Presentation ready.

Optional.

---

## ZIP

Bundle everything.

Recommended export.

# Success Criteria

A user should be able to:

1. Complete workflow

2. Download ZIP

3. Open README

4. Begin implementation immediately

without needing additional planning.

If users still need to create planning documents manually, artifact generation has failed.
