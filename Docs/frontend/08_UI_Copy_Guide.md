# exHacker UI Copy Guide

Version: 1.0

Status: Active

Priority: HIGH

Audience:

* Frontend Engineers
* Designers
* AI Engineers

---

# Purpose

This document defines the language used throughout the application.

Good copy makes a product feel:

```text id="4o6w1y"
Professional
Confident
Intelligent
```

Bad copy makes a product feel:

```text id="lbg19l"
Generic
Template-like
Cheap
```

---

# Tone

exHacker is:

```text id="rrc52v"
Expert
Strategic
Technical
Fast
```

Not:

```text id="l4w0fx"
Funny

Cringe

Overly Corporate

Buzzword-heavy
```

---

# Voice

The product should speak like:

```text id="g3qkkq"
A senior hackathon mentor.
```

Not:

```text id="95ngrw"
A chatbot.
```

---

# Language Rules

Prefer:

```text id="86v4m6"
Analyze

Research

Generate

Evaluate

Architect

Validate
```

Avoid:

```text id="91mvgt"
Magic

Supercharge

Revolutionary

Game-Changing

Next-Level
```

# Golden Rule

Every piece of text should reinforce:

```text id="vpy9w0"
Strategic thinking

Structured execution

Professional project planning
```

Never make the product sound like a chatbot.

Always make it sound like a team of specialists working together.
