# exHacker Frontend Vision

Version: 1.0

Status: Active

Audience:

* Frontend Engineers
* AI Engineers
* Designers

---

# Purpose

This document defines what the frontend should feel like.

Not how it is implemented.

Not component architecture.

Not code.

The goal is to create a frontend that wins hackathon judges.

---

# Core Principle

Most hackathon projects fail because they look like forms.

exHacker must feel like a team of experts working for the user.

The user should not feel like they are filling out forms.

The user should feel like they are directing an AI company.

---

# Emotional Goal

When a judge uses exHacker:

Within 5 seconds:

> I understand what this does.

Within 30 seconds:

> This is much more than a chatbot.

Within 2 minutes:

> This team has built a complete product.

---

# Product Metaphor

Do NOT design exHacker like:

* ChatGPT
* Claude
* Generic SaaS Dashboard

Design it like:

* Mission Control
* AI Operations Center
* Hackathon Command Center

---

# Visual Identity

Keywords:

* Premium
* Modern
* Fast
* Intelligent
* Technical
* Clean

Avoid:

* Cartoon UI
* Playful design
* Excessive gradients
* Crypto aesthetics
* Corporate enterprise styling

Not the AI.

Agents.

Research.

Decision making.

Outputs.

Everything should feel alive.
