This is the interactive Next.js 15 dashboard for **exHacker**. It serves as the visual cockpit where hackathon teams input their challenge, watch the multi-agent orchestration execute in real-time, select their preferred idea, and export their judge deliverables.

---

## ✨ Design & Aesthetic Philosophy
Following our web application design standards, the interface is styled for maximum impact:
*   **Typography**: Outfitted with professional Google Fonts: `Outfit` for strong headings and `Inter` for highly readable body and log content.
*   **Harmonious Color Palette**: Built on dark modes, deep gradients (violet-indigo backgrounds), and neon accent states (emerald for completed, violet for active, amber for human action required).
*   **Micro-Animations**: Features smooth transitions, scale-on-hover effects for cards, and pulsing indicators during running agent nodes to keep the dashboard feeling alive and reactive.
*   **Glassmorphism**: Leverages semi-transparent cards with border rings and backdrop blur to present a premium, modern developer tool look.

## ⚙️ Development Setup

### 1. Installation
Ensure you have [Node.js 18+](https://nodejs.org) installed. Run the following command from the `frontend/` directory:
```bash
npm install
```

### 2. Configure API Endpoint
By default, the frontend expects the backend API at `http://localhost:8000`. You can configure this in your environment or via the shared fetching configs in `src/lib/api.ts`.

### 3. Run Development Server
```bash
npm run dev
# The server will run on: http://localhost:3000
```

## 🎛️ Feature Walkthrough

### 1. Project Creation Wizard
The team fills in details including team size, known and preferred technologies, and the primary hackathon challenge description. 

### 2. Live Agent Stepper
As the LangGraph backend runs, the stepper updates dynamically showing active, completed, and pending states. Clicking on completed steps shows the structured JSON inputs/outputs generated by that node.

### 3. Human Selection Checkpoint
When the workflow hits the validation phase, execution suspends. The UI presents the 5 generated ideas side-by-side alongside their parsed competitor list, GitHub open source projects, and novelty/feasibility scores. Selecting an idea automatically triggers the resume API.

### 4. Export Hub
Once completed, the team gets a one-click copy center and ZIP download showing their full README, PRD, Technical Architecture, Presentation Slides, and 30s/2m/5m Judge Pitches.
